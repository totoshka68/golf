# Приложение «Знаменский» для Android: как получить установочный файл и выложить в RuStore

Это готовый проект-оболочка: внутри лежит текущий интерфейс (запись, игра, статистика, панель клуба).
Собрать установочный файл в той среде, где я работаю, не удалось, потому что там закрыт доступ к серверам Google с набором для сборки.
Поэтому сборка настроена в облаке GitHub. Проект проверен только до этапа «сборка не запускалась»: ошибки при первой сборке возможны, их надо будет поправить.

## Важно до публикации
Сейчас все данные лежат только в памяти телефона, где открыто приложение. У каждого клиента будет своя отдельная «копия клуба» с демо-данными. Для рабочего приложения нужен сервер (общая база, вход по коду). Публиковать в RuStore эту версию для клиентов нельзя: они увидят вымышленные цены и записи. Её можно ставить на телефоны сотрудников для проверки.

## Шаг 1. Пробная версия на вашем телефоне (без подписи, 15 минут)
1. Заведите аккаунт на github.com и создайте пустой закрытый репозиторий, например `znamenskoye-golf`.
2. Загрузите в него все файлы из этой папки (кнопка «Add file → Upload files»). Папка `.github` тоже должна загрузиться.
3. Откройте вкладку «Actions», выберите «Сборка Android», нажмите «Run workflow».
4. Через 5–10 минут в завершённой сборке внизу появится файл `znamenskoye-debug-apk`. Скачайте, распакуйте, перешлите `.apk` на телефон и установите (Android спросит разрешение на установку из файла).

## Шаг 2. Ключ подписи (один раз; потеряете, и приложение нельзя будет обновлять)
Ключ создаётся командой (нужна Java; можно попросить любого разработчика):
```
keytool -genkeypair -v -keystore znamenskoye.jks -alias znamenskoye -keyalg RSA -keysize 2048 -validity 10000
```
Файл `znamenskoye.jks` и пароли храните в двух разных надёжных местах. В репозиторий файл не загружайте.
Затем в репозитории: Settings → Secrets and variables → Actions, добавьте четыре секрета:
- `KEYSTORE_BASE64` — содержимое файла ключа в формате base64 (`base64 -w0 znamenskoye.jks`);
- `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`.
После этого та же сборка выдаст подписанные `.apk` и `.aab` в `znamenskoye-release`.

## Шаг 3. RuStore
1. Консоль разработчика: https://dev.rustore.ru. Регистрация по VK ID, телефону и почте, для физлица проверка по паспорту.
2. Создайте приложение, загрузите подписанный файл из шага 2, заполните карточку из файла `RuStore-карточка.md`.
3. Нужна ссылка на политику конфиденциальности (черновик в карточке; перед публикацией покажите юристу).
4. Модерация проходит несколько дней; правила и требования уточняйте в консоли.

## Что менять при обновлении
Интерфейс собирается в проекте `znamenskoye`. Команда `node prepare.js` копирует его в `www/index.html`, затем загрузите новый `www/index.html` в репозиторий и запустите сборку. Не забудьте увеличить `versionCode` в `android/app/build.gradle` перед каждой загрузкой в RuStore.

## Известные ограничения оболочки
- Шрифты подгружаются из интернета; без сети будут запасные.
- Нет push-уведомлений и входа через VK: это следующий этап вместе с сервером.
- Копирование данных в облако Android отключено (`allowBackup=false`): если удалить приложение, локальные данные пропадут.
